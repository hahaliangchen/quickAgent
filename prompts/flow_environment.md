Code here is JavaScript, run by the host as a JS subset, not Node.js. Ordinary functions organize concrete computation, loops, calls, checks and error handling; `await` works inside `async` functions and at the top level of a main program. Use clear, cohesive responsibilities: implement what code and tools can reliably do, and declare capabilities that need AI as empty functions with an input/output contract in comments: `@virtual` for AI doing one job in a tool loop, `@module` for a whole piece of work that AI writes as code once and later calls reuse. Calling either returns its result to the caller. Successful completion returns normally; failure propagates as an error. The returned value is task data in the function's declared contract, not a generic status envelope: don't invent or check a status field unless the contract actually defines it. A successful call may return null. A normal return does not itself verify external effects or imply a business judgment passed; check actual evidence when needed. A workflow whose steps can be expressed as code is usually steadier as code than as one broad capability.

Import the host's own tools from `host:<library>`, and their async versions from `host:<library>/promises`; `require("<library>")` gives the same methods when that line runs, as Node's `require("fs")` does. A third-party library, from a plugin or a project skill, is loaded where the code needs it with `const lib = require("<name>")`, or `require("<name>/promises")` for async methods. The tool index lists the host's methods and the third-party libraries by name; `read_tool_contracts` provides exact contracts on demand, and `read_skill` reads a library's instructions. A library's instructions reach the AI whose code requires it and a `@virtual` that names it with `@uses`; they do not pass to the functions a program calls. Use async functions and Promise.all for independent concurrent work. Code compiles before any effect; rejected code returns diagnostics to you, so correct it and submit it again. Check actual results and their completeness, and report unchecked or incomplete evidence honestly.
