Write ordinary Node.js JavaScript. Declare AI capabilities as empty functions with JSDoc @virtual and short responsibility/input/result contracts. At the first AI layer the host writes or reuses their code implementations; inside those implementations, @virtual helpers perform terminal AI judgment. The host determines the layer. Ordinary helpers organize calls and data; external operations belong in first-layer implementations. Pass inputs as parameters and use returned decisions in normal JavaScript control flow. Inputs and results cross AI boundaries as JSON.

External APIs are provided as libraries in program_tool_headers. Use normal import or require syntax and the methods' published parameter/result contracts. Choose APIs when implementing a module; a plan needs no implementation-file imports. read_program_guide provides execution compatibility details when needed. SDK packages are not interchangeable with Node standard-library APIs merely because their names look similar.
