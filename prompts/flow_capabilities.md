Flow runtime capabilities (version 14; JS subset, not Node.js):
- Objects have durable [[Prototype]] links. Object.create(proto), Object.getPrototypeOf(value), Object.setPrototypeOf(value,proto), inherited property/method lookup, in, for-in and runtime instanceof are available. Own properties win; deleting an own property reveals inherited values. Object.create(null) has no implicit Object methods. Cycles, changing frozen objects' prototypes and changing Object.prototype's immutable prototype throw TypeError. Built-in methods/constructor links are non-enumerable; Object.keys/JSON/host inputs use own enumerable properties. Array holes read inherited indices in map/iteration/JSON. Function.prototype.call/apply/bind and supported built-in prototypes are real shared objects. Ordinary function new calls bind this, use F.prototype (fallback Object.prototype if it is not an object), and honor returned objects; arrows/async functions/method shorthand/AI declarations are not constructors. Bound constructors delegate to the target. Prototype graphs and partially executed constructors survive GC/host suspension/snapshots. Object(value) boxes primitives, and constructor aliases of the supported built-ins work. Object.create also accepts descriptors. Data/accessor descriptors and Reflect are available; dynamic Function remains unavailable. JSON does not preserve prototype graphs; Runtime snapshots do.
- Functions use strict/module this semantics: top-level and plain calls get undefined; object/computed/optional method calls preserve their receiver. Arrow functions capture lexical this, including in default parameters. f.call(thisArg,...args), f.apply(thisArg,arrayLikeOrNull), f.bind(thisArg,...prefixArgs) work on ordinary/async functions, supported native functions and tools. A bound function keeps its first this and appends arguments when rebound; it survives GC, host waits and snapshots. Array callback methods with a thisArg, Map/Set.forEach and Array.from's mapper honor it. Function name/length are readable; bound functions remain functions for typeof/instanceof Function and are omitted by JSON.stringify. Ordinary prototype chains and ordinary function construction are available; public property descriptors/accessors and Reflect are available; class construction and inheritance are available. Some native Array methods still require an Array receiver. Legacy global call()/ai() wrappers remain unavailable; Function call/apply/bind methods are supported.
- Turn-local setTimeout(callback, delay, ...args), setInterval, clearTimeout, clearInterval and queueMicrotask are available. Timer handles are numeric IDs, not Node Timeout objects (no ref/unref/refresh or Node Timeout this object; plain timer callbacks have undefined this, while bind/arrows preserve their receiver). Delays are truncated to milliseconds, clamped to 1 for values below 1, non-finite values or values above 2147483647. Promise jobs and queueMicrotask share a FIFO microtask queue; drain it before each timer callback. Timers keep the program alive. Callback errors are uncaught program errors; returned values are ignored. Callback functions/arguments and absolute due times survive pause/snapshots; overdue intervals fire once, without replaying missed ticks. Turn stop/end cancels timers. This is not a cross-turn scheduling API.
- Top-level statements run in order. Top-level return is invalid; put data the program needs in its code or read it with the imported tools. Define ordinary top-level functions and call them with positional parameters; missing arguments are undefined and extra ones are ignored, but @virtual and @module functions take exactly their parameters.
- Values use an internal VM heap; objects and arrays preserve identity across ordinary calls. Supported syntax includes const/let/var, arrays and objects, destructuring and defaults in declarations, ordinary function parameters and catch, literal spread, spread in calls and rest parameters, optional function calls, local assignment and updates, object/index assignment and updates, arithmetic and comparisons, if/else, ternary, for/for-of/for-in with simple bindings, switch, labeled break/continue, try/catch/finally/throw, template strings and assert. let/const are block-scoped: an inner block may redeclare and shadow a name, and reading one before its declaration throws ReferenceError. var is function-scoped and hoisted. Non-simple parameters initialize in a separate parameter scope, so defaults and their closures cannot see body bindings. A function sees its own variables and top-level ones, not its caller's locals; pass those as arguments. Empty strings, false, null and zero are false; objects and arrays are true. `&&` and `||` return operands. Tool and AI inputs/outputs cross a JSON boundary; cyclic and non-JSON values are rejected there.
- Common strings/arrays support includes, indexOf, slice, at, concat; strings support lastIndexOf, startsWith, endsWith, trim, case conversion, split, replace, replaceAll, match; arrays support push and join. Functions are values: nested function declarations, function expressions, arrows and object method shorthand create closures over their enclosing scope that can be stored, passed and called; built-ins such as String and imported tools can be used as values too. Array callback methods accept synchronous function values, multi-statement and nested callbacks; callbacks can call tools and resume after persistence. String replace/replaceAll also accept replacement functions. Array map also accepts async callbacks. JSON.parse/stringify, Array.isArray, Object.keys/values and typeof are available. Regex literals support test and match, not full JavaScript RegExp.
- `path.join/resolve/relative/normalize/dirname/basename/extname` and `url.parse` are deterministic Rust-backed computations, not Node imports or filesystem access.
- Array(n) and new Array(n) create n holes when their only argument is a number (integer >= 0); other arguments are elements. The runtime array limit is 1,000,000. length, index assignment, fill, sparse callbacks and JSON.stringify preserve holes as in JS. String.raw tagged templates preserve backslashes and interpolate values. String.fromCharCode(...units), String.fromCodePoint(...points), Object.hasOwn(object,key), shallow Object.freeze(object), encodeURIComponent/decodeURIComponent and structuredClone(JSON_value) are available. freeze returns the same reference and strict writes throw TypeError; clone creates independent nested objects. Invalid URI encodings throw URIError. Regex exec, non-global match and each matchAll row have groups (undefined without named captures), index and input; replacement supports $<name>. Global match follows JS and returns only matched strings.
- Date.now(), new Date(), new Date(milliseconds), new Date(ISO_string), new Date(year,month,day[,hours,minutes,seconds,milliseconds]), Date.parse and Date.UTC are available. Dates preserve internal milliseconds across host suspension and heap snapshots. Instance methods: getTime/valueOf, toISOString/toJSON/toString, getFullYear/Month/Date/Day/Hours/Minutes/Seconds/Milliseconds and their getUTC* counterparts. Local dates follow the host timezone; UTC getters are portable. Subtraction, numeric conversion (+date), relational comparison and instanceof Date work; JSON.stringify serializes Date through its ISO representation (invalid dates as null). Invalid Date.getTime() is NaN and toISOString throws RangeError. Date and Math.random accept runtime nondeterminism. Setters and toLocaleString/toLocaleDateString/toLocaleTimeString are unavailable; locale methods are rejected at compile time because there is no locale data, so use toISOString or format components yourself. read_program_guide also returns builtin_contracts with signatures.
- `import * as io from "host:io"` and `import {read as load} from "host:io"` bind the host's own authorized tools; `const io = require("io")` gives the same methods when that line runs, as Node's `require("fs")`. Without imports, the host's libraries are in scope by name, and a variable the source declares with the same name is its own. Tool methods accept one JSON object and return their actual tool result. Use `read_tool_contracts` for real names, parameters and return contracts.
- `const ppt = require("ppt")` loads a third-party library, from a plugin or a project skill, when that line runs and gives an object of its methods; `require("ppt/promises")` gives async ones. The name is a string literal. Requiring a library again in one run gives the same object. A library that cannot be found throws an error with code MODULE_NOT_FOUND at that line, which code can catch; a method the library lacks throws where it is called. host: imports only the host's own libraries. A skill with instructions alone can be required too: its object has no methods, and requiring it brings its instructions to the code.
- An empty function with an adjacent `@virtual` or `@module` comment declares AI work and its return contract; it may also be nested inside another function. Ordinary functions use their implemented body; unannotated empty functions are valid and return undefined. A `@virtual` function runs as a tool loop with the tools its declaring code imports and requires. A `@module` function is code AI writes when it is first called; later calls with the same contract in this conversation run that code.
- A @virtual function sees only its arguments and the outer variables its comment names with JSDoc `@uses <name>` tags, its closure: each must be in scope where the function is declared and is read when it is called. Naming a variable a library was required into gives the function that library's instructions; skill instructions do not otherwise pass to the functions a program calls. A @module gets everything as parameters; `@uses` on it is a compile error. Async AI functions run in independent windows. Promise.all collects results in input order. Model requests share the configured concurrency limit.
- async functions return Promises; await suspends and resumes. Promise.resolve/reject, new Promise, then/catch/finally and Promise.all/allSettled/race/any are available. Import the host's async tools from host:<library>/promises, or require("<name>/promises") for any library's; independent file reads may be batched. Errors propagate through await. Promise ordering follows JavaScript microtask order, including the extra turns when a Promise resolves to another Promise. Using a call of a top-level async function or a /promises tool directly as a value (reading a property, an operator, a condition, assert or a template) without await is a compile error; save the Promise or await it. Await assimilates ordinary thenables; general Promise.resolve/executor thenable assimilation remains incomplete; extracted Promise methods can be called with call/apply/bind using the correct Promise receiver. Synchronous and asynchronous generators are supported; call()/ai() wrappers remain unsupported. The runtime is a JS subset, not Node.js.
- `console.log`, `console.info`, `console.warn`, `console.error` and `console.debug` print complete records, as in Node: strings as they are, other values as JSON. Captured output is retained. If capture memory or AI delivery capacity is exhausted, the program fails explicitly with a saved-output reference instead of dropping records or cutting their text.
- Tool and AI calls can fail; exceptions can be handled. An uncaught error in a module goes to an AI that fixes the module's file, after which the call runs again; in the main program it goes back to the main AI. Do not repeat effects with unknown outcomes or claim acceptance based only on successful execution.

Full stdout/stderr enter JS heap, not AI context. Check running and exit_code before parsing. If complete output exceeds the heap delivery budget, SHELL_OUTPUT_OVER_CAPACITY stops the program; no successful prefix is delivered. The error preserves the output asset and session reference. Read needed stream/char_offset pages or process a narrower saved range without rerunning the command. Module returns also stay in JS. Prints, explicit AI inputs, diagnostics and outcomes enter AI context. OUTPUT_OVER_CAPACITY stops delivery when complete material does not fit, with the original saved and a read reference. Revise the orchestration from that evidence, preserving completed operations. ContextOverflow means the AI request itself cannot fit.
Define modules by the result the caller needs, such as verified facts, counts, or an evidence-based answer with file and line references. A generic command runner may be reused as an implementation detail, but its ability to run commands alone does not satisfy an analysis contract. Reuse a module only when its promised result fits this task. Implement known steps as ordinary JavaScript. For code reasoning, supply complete relevant units including enclosing conditions and earlier returns; a search hit proves only the matched line. A focused @virtual may judge prepared evidence when needed, but is optional. Do not apply arbitrary head/slice character cuts to evidence. Print an appropriate complete unit with its file and line range; when delivery fails, read the saved result in explicit ranges or change the work division. Unread content is not evidence. Verify a behavior claim against its full control path or actual execution; state whether a test was read or actually run.


Execution budgets: up to 1,000,000 VM instructions between completed host interactions, plus a 30-minute wall deadline for the whole program (including host waits and pause time). Snapshots preserve counters and deadline. A genuine host reply or dispatching a due host timer starts the next instruction segment; calling next(), restoring state, or pure Promise/queueMicrotask jobs do not. INSTRUCTION_BUDGET_EXHAUSTED / PROGRAM_TIME_BUDGET_EXHAUSTED stops execution and reports used/limit, total instructions, location and hot_lines. Inspect unknown interrupted effects before retrying; no automatic replay.

- Collections: new Map/Set/WeakMap/WeakSet accept synchronous iterables or null/undefined. Map/Set support size, has/delete/clear, get/set or add, keys/values/entries and forEach. SameValueZero keys preserve object identity; -0 is stored as +0. Iterators are live across mutation and remain done once exhausted. Built-in for...of, spread, array destructuring, Array.from (mapper is interleaved), Object.fromEntries and Promise combinators accept collections/iterators. Entries and iterator positions survive Runtime snapshots and host suspension; forEach callbacks run as resumable VM frames. WeakMap/WeakSet accept object keys, retain them strongly, and have no size/clear/enumeration. JSON.stringify and host/AI JSON boundaries see only enumerable properties, normally {}; use Array.from to transmit collection data. Map/Set forEach accepts thisArg. Prototype inheritance is available. async iteration remains unavailable.

- Property descriptors: Object.defineProperty/defineProperties, getOwnPropertyDescriptor(s), getOwnPropertyNames/Symbols, preventExtensions/isExtensible, seal/isSealed and freeze/isFrozen are available. New descriptors default missing flags to false; redefinition retains existing fields. Data and accessor descriptors cannot be mixed. Getter/setter literals and descriptor functions keep this, propagate exceptions and can suspend on host calls with snapshot/GC safety. Nonconfigurable and readonly data attributes are enforced, including array length truncation and strict deletion. A frozen accessor can still run its setter. Object.values/entries/assign, object spread/destructuring, JSON.stringify, array callbacks/iteration and Array.from execute the getters they read; key-only/descriptor queries do not. Reflect supports apply/construct, get/set (optional receiver), defineProperty/deleteProperty, has, ownKeys, getOwnPropertyDescriptor, get/setPrototypeOf and isExtensible/preventExtensions. Invalid targets/descriptors throw TypeError; valid operations denied by attributes return false for Reflect set/define/delete/prototype changes. Reflect.ownKeys includes string and Symbol keys; getOwnPropertySymbols returns the Symbol keys. Runtime snapshots preserve descriptors, accessor closures and integrity levels; JSON does not preserve them. Dynamic Function/eval and Proxy remain unavailable.

Host/AI JSON export rejects enumerable accessors instead of dropping them; explicitly read fields or JSON.stringify to materialize. Native array readers not yet moved into resumable frames reject accessor elements; Array.from(array) materializes them first.

- Symbol(description), description, Symbol.for/keyFor, typeof symbol and Object(symbol) are available. Each symbol has identity independent of its description; registry entries, keys and identity survive GC/snapshots. String(symbol) explicitly produces descriptive text; implicit string/number conversion throws. Symbol keys work with computed properties, inherited accessors/descriptors, in/delete, Reflect and Map/Set keys. Object.keys/values/entries, for-in and JSON ignore Symbol keys; assign/spread/rest and getOwnPropertyDescriptors include them. JSON.stringify omits Symbol-valued object fields, uses null in arrays and returns undefined for a top-level symbol. Symbols are not JSON data across tool/AI boundaries; print String(symbol) or a data representation.
- Supported well-known symbols: iterator, asyncIterator, hasInstance, toPrimitive and toStringTag. The synchronous iterable protocol is used by for-of, array/call spread, array destructuring, Array.from, Map/Set/weak collection construction, Object.fromEntries and Promise combinators; built-in Array/String/Map/Set iterators implement it. GetIterator caches next once, validates iterator/results, and keeps receiver/state. break/return/throw and failing consumers close with return; normal exhaustion does not, and next/done/value failures are propagated without a second close. A pending original throw wins over cleanup errors. Destructuring closes partial iteration, while rest drains it. Iterator records, cursors, closures, flags and a suspended next/return survive Runtime snapshots. Symbol.asyncIterator drives for-await and async generators; synchronous generators are also available. Symbol.species/isConcatSpreadable and regex symbol hooks are later work. instanceof and Object.prototype.toString honor hasInstance/toStringTag. toPrimitive is used by property-key, operator/template, String/Number and single-object Date conversions; ordinary conversion methods are used when the hook is absent.

- Classes: declarations and expressions, constructors (including defaults), extends, instance/static methods, computed string/Symbol names and getters/setters are available. Class bodies are strict; methods are non-enumerable and cannot be constructed, class constructors require new, and the inner class name is immutable and in its temporal dead zone until definition completes. new.target is undefined in ordinary calls/methods, identifies the effective constructor in new/Reflect.construct/bound construction, and is lexically captured by arrows. Derived this is uninitialized until super(); missing/double super and invalid primitive constructor returns throw. super property access preserves the actual receiver and the method's defining home object, including extracted methods and arrows; reads, writes, updates, compound assignments and super() can suspend and resume. Existing native constructors (including Error, Array, collections, Date, Promise and primitive wrappers) preserve their native slots when subclassed. Class/prototype/home-object links, constructor state and new.target survive GC and Runtime snapshots. JSON transmits enumerable data, not class identity or methods. Public/private fields, static blocks, dynamic Function/eval, async iteration, species construction and full built-in method genericity remain outside this stage.

- Function/class names are inferred for anonymous function expressions, arrows and classes in identifier declarations/assignments, logical assignments, parameter/destructuring defaults and object property values (including Symbol names). Explicit names and class static name members win; inference does not create a lexical self-binding. Name metadata and UTF-16 code units survive snapshots. Ordinary compound assignments do not infer names.
- Promise reactions use ordinary durable invocation for local callbacks: native functions, classes, extracted methods, coercion hooks and async functions keep the same call semantics and error behavior. Only real host/AI calls cross the JSON boundary. Native callback failures retain the registration call site's location, including across snapshots; user function errors retain their own source location. Dynamic Function/eval remain disabled with explicit EvalError diagnostics.
- Number.prototype.toExponential(fractionDigits?) is available on primitive/boxed numbers and Number subclasses. Omitted digits use shortest exponential notation; explicit digits support 0..100 with exact decimal rounding. Invalid receivers throw TypeError, invalid digits throw RangeError, and digit conversion can suspend on host calls. NaN/Infinity follow the standard conversion/check order.

- Synchronous generators: function* declarations/expressions and object/class generator methods, yield/yield*, next/return/throw and existing synchronous iterable consumers are supported. Parameters initialize at call time; the body starts at first next. Each iterator preserves local state, this/home object, catch/finally and pending abrupt completion across yields, GC, host calls and Runtime snapshots. yield* caches next, forwards return/throw and preserves delegated result identity. Reentrant resumes throw TypeError; generators are not constructors. structuredClone cannot clone them and JSON only carries enumerable data, not execution state. Async generators and for-await are also supported (see below); dynamic GeneratorFunction/AsyncGeneratorFunction construction remains unavailable.

- Async iteration: async function* declarations/expressions and object/class methods, for-await-of, async yield/yield*, and Promise-returning next/return/throw are supported. Requests queue while executing/awaiting. Yield and explicit return expressions await their values; bare return and implicit completion do not add that await. return(value) awaits its argument; next/throw inputs are not unwrapped. for-await prefers Symbol.asyncIterator, otherwise adapts a synchronous iterator and awaits its values. Actual async iterator values (including Promise values from async yield*) are retained. Cache next once, validate iterator results, await return on abrupt loop exit, and preserve an original throw over cleanup errors. Await supports thenable assimilation and observable Promise.constructor lookups; general Promise.resolve/executor thenable assimilation remains incomplete. Queues, awaited values, suspended frames, closures, catch/finally and pending completions survive GC and Runtime snapshots without replay. Dynamic AsyncGeneratorFunction is unavailable. JSON/structuredClone do not preserve generator execution state.
