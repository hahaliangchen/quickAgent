JavaScript orchestration reference for the resumable Rust VM (runtime version 14). Consult this reference when an API or diagnostic requires execution details; it is not a workflow template.

Write JavaScript using the supported built-ins and host-published libraries. This deployment runs source in strict module mode and supports the following language features: let/const/var, if/else and every loop form, destructuring and spread, arrows and closures, classes with inheritance, public and private members and static blocks, getters/setters, function* and yield, async/await, async generators and for await, Promise.all and the other combinators, Map/Set/WeakMap/WeakSet, Symbol and iterators, Reflect, property descriptors, prototypes, optional chaining, logical assignment, tagged templates, and RegExp with lookaround, backreferences and \p{}. Standard built-ins include Array, String.fromCharCode, String.fromCodePoint, Object.hasOwn, Object.freeze, encodeURIComponent, decodeURIComponent, structuredClone, Date.now, Date.parse and Date.UTC. The VM executes both orchestration and saved implementations; it supplies its own import/require bindings for host libraries. Everything below is what this host adds or does differently.

Program shape
- Top-level statements run in order. The host calls no function a program declares: every function runs only where your code calls it, so a main() helper needs `await main();` at the top level, and a function nothing calls or passes on is a compile error. In a module implementation the host calls only its entry function. Top-level return is invalid. Put the data a program needs in its code or read it with the imported tools. await works at the top level of a main program.
- A function sees its own variables and the top-level ones, not its caller's locals; pass those as arguments. Ordinary functions take arguments as JS does; @virtual functions take exactly their parameters.
- assert(condition, message) is available everywhere; on failure it throws message itself, not an Error object. Running state, including closures, generators, pending Promises and timers, survives pauses and host waits without any work on your part.

Libraries
- `import io from "io"`, `import * as io from "io"`, and `import {read as load} from "io"` bind the host's authorized SDK tools; `const io = require("io")` gives the same methods when that line runs. The old `host:` prefix is a compatibility alias supported in both import and require. Load async versions from `<library>/promises`. Without imports, the host's libraries are in scope by name, and a variable the source declares with the same name is its own. Tool methods accept one JSON object and return their actual tool result. Use `read_tool_contracts` for real names, parameters and return contracts.
- `const ppt = require("ppt")` loads a host-registered third-party library, from a plugin or a project skill, when that line runs and gives an object of its methods; `require("ppt/promises")` gives async ones. The name is a string literal. Requiring a library again in one run gives the same object. A library that cannot be found throws an error with code MODULE_NOT_FOUND at that line, which code can catch; a method the library lacks throws where it is called. Static imports bind published host SDK libraries; registered plugin and skill libraries load at runtime with require. This does not resolve npm packages or local files. A skill with instructions alone can be required too: its object has no methods, and requiring it brings its instructions to the code.
- `path.join/resolve/relative/normalize/dirname/basename/extname` and `url.parse(value, base)` are deterministic computations that do not touch the filesystem. path.resolve needs at least one absolute path and path.relative needs two.
- `require("yaml")` gives `parse(text)` and `stringify(value)`, and `require("js-yaml")` gives `load(text)` and `dump(value)`: one YAML document, mapping keys as strings, merge keys applied.
- `atob`/`btoa` decode and encode base64; `new TextEncoder().encode(text)` gives UTF-8 bytes and `Buffer.byteLength(text)` their count; `os.homedir()`, `os.platform()`, `os.tmpdir()` and `process.env.NAME` read the environment (credential-like names are refused). `path`, `url` and `os` can also be required.
- Do not hand-write general-purpose encoders, decoders, parsers or converters (base64, UTF-8 or byte counting, YAML, JSON, HTML, CSV, URL, dates) when the runtime lacks one: a per-character loop in the VM is slow and exhausts the instruction budget. Use the built-ins above and host libraries. When something you need is unavailable, do not reimplement it: do the task another permitted way, or report the missing capability in the result so the host can add it.

AI functions
- A module implementation is an ordinary module: its entry function, helpers, imports, and top-level statements such as constants and `require` calls. Each call runs those statements first in a fresh module scope, so module-level variables do not carry over between calls. Top-level await is unavailable; await inside functions.
- Declare both AI layers with JSDoc @virtual on an empty function, describing responsibility, parameters and return values. In the main orchestration the host resolves each virtual function to saved implementation code, or asks an author to write it. Pass inputs as parameters rather than @uses; no implementation-file import is needed. These first-layer implementations are stored as modules internally and can be reused by contract.
- Inside a first-layer implementation, an @virtual helper performs focused AI judgment or generation in a terminal tool loop. It sees authorized non-shell methods its declaring code imports/requires. @uses names lexical captures and skill-library instructions; skills are not otherwise inherited. Unannotated empty functions are ordinary JS and return undefined. There are no global call()/ai() wrappers.
- The host assigns each AI role from its real execution boundary and checks persisted caller ancestry. Ordinary helpers add no AI layer. A second-layer virtual cannot submit another program or create a third AI layer (VIRTUAL_LAYER_LIMIT). Async AI functions run in independent windows under the configured concurrency limit. The legacy @module tag remains compatible at the first layer; new declarations use @virtual at both layers.
- An implemented entry must have a real body; its original annotation may remain. Other AI declarations still require empty bodies. Probe source uses the same SDK names, but probe:true only permits read_file, read_file_lines, search_text, list_dir and workspace_info. Shell and writes fail with MODULE_PROBE_READ_ONLY; omit probe to submit the implementation with normal permissions.

JSON boundary
Tool and AI inputs and outputs are JSON; values inside the program keep their identity. At the boundary, cyclic values, non-finite numbers and enumerable accessors are rejected, so read such fields explicitly first. A Map or Set arrives as {}, so pass Array.from(collection). Symbols, class identity, methods, prototypes and generator state do not cross.

Checks and errors
- The whole source compiles before any effect; a diagnostic means nothing ran, so correct it and submit again. Undeclared names and unknown host library methods are rejected there.
- Using a call of a top-level async function or a /promises tool directly as a value (reading a property, an operator, a condition, assert or a template) without await is a compile error; save the Promise or await it.
- Tool and AI calls can fail, and exceptions can be handled. An uncaught error in a module goes to an AI that fixes the module's file, after which the call runs again; in the main program it goes back to the main AI. Do not repeat effects with unknown outcomes or claim acceptance based only on successful execution.
- `console.log`, `info`, `warn`, `error` and `debug` output complete records: strings as they are, other values as JSON.

Timers
setTimeout, setInterval, clearTimeout, clearInterval and queueMicrotask work within the current turn. Handles are numbers, not Node Timeout objects. Pending timers keep the program alive, the end of the turn cancels them, and an overdue interval fires once without replaying missed ticks. They cannot schedule work across turns.

Limits
Arrays hold at most 1,000,000 items. A regex pattern is at most 8192 bytes, its input at most 2 MiB, and its results at most 10000 items and 4 MiB of captures. Backtracking patterns have a step limit and fail with an error when they exceed it. Regex flags are g, i, m, s, u and y.

Differences that give no error
- String length, indexes, slice and indexOf count Unicode scalar values, not UTF-16 units: '😀'.length is 1. charCodeAt still returns a UTF-16 unit.
- Error objects have no stack. Promise.any rejects with an error named AggregateError that has errors, but it is not instanceof AggregateError.
- matchAll returns an array. A regex backreference to a group that did not take part in the match fails instead of matching the empty string.
- WeakMap and WeakSet hold their keys strongly. Symbol.species and Symbol.isConcatSpreadable exist but built-ins ignore them, so map on an Array subclass returns a plain Array. Regex symbols such as Symbol.match are undefined.
- Local Date methods follow the host timezone, so use UTC methods for portable results. toLocale* covers en and zh and the UTC or host time zone; other locales and time zones throw RangeError. Default formats match Node, but with hour, year or hour12 options the output can differ from Node without an error, so build the string from the component getters when the exact format matters.

Not available
- Rejected at compile time: Proxy, BigInt, WeakRef, typed arrays, eval and Function, Intl, globalThis, export, filesystem module imports, dynamic import(), TypeScript syntax, Object.groupBy, Math.clz32, Math.imul, String.prototype.normalize, a JSON.parse reviver, regex flags d and v.
- Throw only when reached, after earlier effects have happened: Date setters, toUTCString, toDateString, toPrecision, copyWithin, Array with and toSpliced, Promise.withResolvers, a function replacer for JSON.stringify, structuredClone of anything but JSON values, and Array.prototype methods borrowed for a non-array receiver (use Array.from first).
- A Promise used as if it were its result also throws when reached: reading a property it does not have or converting it to a number or string is a TypeError saying it may need await. That includes an async comparator passed to sort.

Execution limits
The default budget is 2,000,000 user-work units between completed host interactions and a 30-minute whole-program wall deadline, including waits and pauses. Prelude internals are billed by entry and iteration; user callbacks are metered normally. Independent physical-step checks preserve the deadline. Snapshots retain limits and remaining work; restoring or pure microtasks do not refill the budget. Exhaustion reports user-source location/hot_lines and keeps completed effects. Read the actual diagnostic before revising remaining work; never replay an external write whose outcome is unknown.
