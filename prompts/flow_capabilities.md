JavaScript orchestration reference for the resumable Rust VM (runtime version 14). Consult this reference when an API or diagnostic requires execution details; it is not a workflow template.

Write JavaScript using the supported built-ins and host-published libraries. This deployment runs source in strict module mode and supports the following language features: let/const/var, if/else and every loop form, destructuring and spread, arrows and closures, classes with inheritance, public and private members and static blocks, getters/setters, function* and yield, async/await, async generators and for await, Promise.all and the other combinators, Map/Set/WeakMap/WeakSet, Symbol and iterators, Reflect, property descriptors, prototypes, optional chaining, logical assignment, tagged templates, and RegExp with lookaround, backreferences and \p{}. Standard built-ins include Array, String.fromCharCode, String.fromCodePoint, Object.hasOwn, Object.freeze, encodeURIComponent, decodeURIComponent, structuredClone, Date.now, Date.parse and Date.UTC. The VM also supports Object.groupBy, Map.groupBy, Array.prototype.toSpliced, Array.prototype.with, Promise.withResolvers, Set.prototype.union, Set.prototype.intersection, Set.prototype.difference, Set.prototype.symmetricDifference, Set.prototype.isSubsetOf, Set.prototype.isSupersetOf, Set.prototype.isDisjointFrom, and RegExp.escape. The VM executes both orchestration and saved implementations; it supplies its own import/require bindings for host libraries. Everything below is what this host adds or does differently.

Program shape
- Top-level statements run in order in a fresh one-shot program. Every declared function runs only where your code calls it and an unused function is a compile error. A capability implementation is entered by its declared function and otherwise follows ordinary function rules. Top-level `return` is the normal way for the main orchestration to deliver its final structured result; implementation entries return from their own functions. Put the data a program needs in its code or read it with the imported tools. `await` works at the top level of the main program.
- When `process.exec_command` returns `running: true` with a `session_id`, wait for completion with `process.write_stdin` on that session instead of reading incomplete logs early or starting a second build in the same target directory.
- A function sees its own variables and the top-level ones, not its caller's locals; pass those as arguments. Ordinary functions take arguments as JS does; @virtual functions take exactly their parameters.
- assert(condition, message) is available everywhere; on failure it throws message itself, not an Error object. Running state, including closures, generators, pending Promises and timers, survives pauses and host waits without any work on your part.

Libraries
- `import io from "io"`, `import * as io from "io"`, and `import {read as load} from "io"` bind the host's authorized SDK tools; `const io = require("io")` gives the same methods when that line runs. The default library surface is synchronous-looking: a call returns its actual tool result to the next statement, while the VM saves the current frame and resumes it when the host receipt arrives. The old `host:` prefix is a compatibility alias supported in both import and require. Load async versions from `<library>/promises` only for deliberate concurrency or Promise composition. Without imports, the host's libraries are in scope by name, and a variable the source declares with the same name is its own. Tool methods accept one JSON object and return their actual tool result. Use `read_tool_contracts` for real names, parameters and return contracts.
- `const ppt = require("ppt")` loads a host-registered third-party library, from a plugin or a project skill, when that line runs and gives an object of its methods; `require("ppt/promises")` gives async ones. The name may be a string literal or a string-valued expression. Requiring a library again in one run gives the same object. A library that cannot be found throws an error with code MODULE_NOT_FOUND at that line, which code can catch; a method the library lacks throws where it is called. Static imports bind published host SDK libraries; registered plugin and skill libraries load at runtime with require. This does not resolve npm packages or local files. A skill with instructions alone can be required too: its object has no methods, and requiring it brings its instructions to the code.
- Exact-text edit rule: this is mandatory for `io.edit` and `io.replace`, not a style preference. If `old_text`, `new_text`, or `replacement` contains any backslash, including `\n`, `\\`, `\t`, or a regular expression, write that value with the `String.raw` tag, for example String.raw`...`; never use an ordinary quoted JS string for that value. String.raw preserves backslashes and removes the JavaScript string-escape layer. It does not turn `\n` into a real newline: put intended real line breaks directly in the raw template. Interpolation such as `${value}` is still evaluated, so use it only intentionally.
- `path.join/resolve/relative/normalize/dirname/basename/extname` and `url.parse(value, base)` are deterministic computations that do not touch the filesystem. path.resolve needs at least one absolute path and path.relative needs two.
- `require("yaml")` gives `parse(text)` and `stringify(value)`, and `require("js-yaml")` gives `load(text)` and `dump(value)`: one YAML document, mapping keys as strings, merge keys applied.
- `atob`/`btoa` decode and encode base64; `new TextEncoder().encode(text)` gives UTF-8 bytes and `Buffer.byteLength(text)` their count; Buffer has no other methods. `os.homedir()`, `os.platform()` and `os.tmpdir()` read the environment, and `process.env.NAME` or `process.env["NAME"]` reads one variable (credential-like names are refused) when the source does not bind the name `process` itself; there is no other Node process object. `path`, `url` and `os` can also be required.
- Do not hand-write general-purpose encoders, decoders, parsers or converters (base64, UTF-8 or byte counting, YAML, JSON, HTML, CSV, URL, dates) when the runtime lacks one: a per-character loop in the VM is slow and exhausts the instruction budget. Use the built-ins above and host libraries. When something you need is unavailable, do not reimplement it: do the task another permitted way, or report the missing capability in the result so the host can add it.

AI functions
- Declare a single-layer AI leaf capability with JSDoc `@virtual` (empty body or partial JS ahead of a trailing `// ...` intent comment), describing its responsibility, inputs and return shape. `@virtual` always runs directly as a terminal AI tool loop (`ai_layer = 1`); there is no second virtual AI layer, and a `@virtual` leaf cannot call `write_program` or spawn further AI calls.
- An early JS `return` inside a partial `@virtual` completes locally without calling AI; reaching the trailing comment hands execution to the leaf AI with live local and closure variables in scope (and optional `subContext` from `host.context()`).
- `@module` (when explicitly used for a standalone reusable pure-parameter deterministic helper) compiles as ordinary JS/host-library code without `@uses` captures and cannot declare nested `@virtual` helpers. Unannotated empty functions are ordinary JS returning `undefined`; a called empty function with a contract comment but no `@virtual` tag is a compile error, since it would silently do nothing. There are no global `call()/ai()` wrappers.
- The host controls capability scheduling, persistence and concurrency. Async capabilities run in independent windows under the configured concurrency limit. An implemented entry must have a real body; other abstract declarations remain empty. `@virtual` declarations accept ordinary JavaScript parameter patterns and the host binds them positionally. A probe source is a script: the host wraps its top-level statements in the called async entry, so top-level await and return are valid there. Probe source uses the same SDK names, but `probe:true` only permits `io.read`, `io.read_lines`, `io.search`, `io.list`, `io.workspace_info`, and read-only `git.status`, `git.diff`, `git.log`. Shell and writes fail with `MODULE_PROBE_READ_ONLY`; omit probe to submit the implementation with normal permissions.

JSON boundary
Tool and AI inputs and outputs are JSON; values inside the program keep their identity. At the boundary, cyclic values, non-finite numbers and enumerable accessors are rejected, so read such fields explicitly first. A Map or Set arrives as {}, so pass Array.from(collection). Symbols, class identity, methods, prototypes and generator state do not cross.

Checks and errors
- The whole source compiles before any effect; a diagnostic means nothing ran, so correct it and submit again. Undeclared names and unknown host library methods are rejected there.
- Ordinary host methods and non-async `@virtual` capabilities may be used directly as values; the VM suspends and resumes at that call site. Using a call of a top-level async function or a /promises tool directly as a value (reading a property, an operator, a condition, assert or a template) without await is a compile error; save the Promise or await it.
- Tool and capability calls can fail, and exceptions can be handled. An uncaught error in a capability implementation goes to an AI that fixes its saved implementation, after which the call runs again; in the main program it goes back to the main AI. Do not repeat effects with unknown outcomes or claim acceptance based only on successful execution.
- `console.log`, `info`, `warn`, `error`, `debug` and `console.dir` remain ordinary runtime compatibility methods. Use them only when the user explicitly asks for diagnostic logging; return structured summaries for normal orchestration results.

Timers
setTimeout, setInterval, clearTimeout, clearInterval and queueMicrotask work within the current turn. Handles are numbers, not Node Timeout objects. Pending timers keep the program alive, the end of the turn cancels them, and an overdue interval fires once without replaying missed ticks. They cannot schedule work across turns.

Limits
Arrays hold at most 1,000,000 items. A regex pattern is at most 8192 bytes, its input at most 2 MiB, and its results at most 10000 items and 4 MiB of captures. Backtracking patterns have a step limit and fail with an error when they exceed it. Regex flags are g, i, m, s, u and y.

Differences that give no error
- String length, indexes, slice and indexOf count Unicode scalar values, not UTF-16 units: '😀'.length is 1. charCodeAt still returns a UTF-16 unit.
- Error objects have no stack. Promise.any rejects with an error named AggregateError that has errors, but it is not instanceof AggregateError.
- matchAll returns an array. A regex backreference to a group that did not take part in the match fails instead of matching the empty string.
- WeakMap and WeakSet hold their keys strongly. Symbol.species and Symbol.isConcatSpreadable exist but built-ins ignore them, so map on an Array subclass returns a plain Array. Regex symbols such as Symbol.match are undefined.
- Local Date methods follow the host timezone, so use UTC methods for portable results. toLocale* covers en and zh and the UTC or host time zone; other locales and time zones throw RangeError. Default formats match Node, but with hour, year or hour12 options the output can differ from Node without an error, so build the string from the component getters when the exact format matters.

Not available
- Rejected at compile time: Proxy, BigInt, WeakRef, typed arrays, eval and Function, Intl, export, filesystem module imports, dynamic import(), TypeScript syntax, Math.clz32, Math.imul, String.prototype.normalize, a JSON.parse reviver, regex flags d and v.
- Throw only when reached, after earlier effects have happened: Date setters, toUTCString, toDateString, toPrecision, copyWithin, a function replacer for JSON.stringify, structuredClone of anything but JSON values, and most Array.prototype methods borrowed for a non-array receiver (use Array.from first; toSpliced and with accept array-likes).
- A Promise used as if it were its result also throws when reached: reading a property it does not have or converting it to a number or string is a TypeError saying it may need await. That includes an async comparator passed to sort.

Execution limits
The default budget is 2,000,000 user-work units between completed host interactions and a 30-minute whole-program wall deadline, including waits and pauses. Prelude internals are billed by entry and iteration; user callbacks are metered normally. Independent physical-step checks preserve the deadline. Snapshots retain limits and remaining work; restoring or pure microtasks do not refill the budget. Exhaustion reports user-source location/hot_lines and keeps completed effects. Read the actual diagnostic before revising remaining work; never replay an external write whose outcome is unknown.
## Context-as-Code protocol

Execution steps use one plain-text `<run>...</run>` block. A complete Markdown response without `<run>` closes the current turn. The host keeps code segments in a persistent VM only within the current user turn and creates a blank VM for the next turn. Reuse the smallest read-only fragment from earlier turns and verify current state before any side effect. Host libraries are injected as structured JavaScript APIs and business JSON tool schemas are omitted from model requests.
