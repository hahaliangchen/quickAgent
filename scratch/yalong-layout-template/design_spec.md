# 联通汇报版式模板

16:9，设计视图 1280×720。白底，联通红 #E60012 为主色，深红 #B8000E 与浅粉 #FDEDEE 为辅色，正文黑灰。字体 Microsoft YaHei。

## 固定品牌元素

每页右上角“中国联通 | 联通元景”标识、左上红色竖条、页眉下的红色分隔线保持原样，不移动、不遮挡、不重画。封面、目录、结尾页沿用原模板品牌构图。

## 封面、目录与结束页

- **目录**：每个目录项是一个块（编号方块 + 标题栏），用 fill_layout 按条目提交，宿主增删并等距排列。目录条目与正文章节一一对应，每条都要有对应的正文页；不要另加“总结”“结语”等没有对应页面的条目。
- **单位、汇报人、日期**：用户材料里给了就照写；没给就不要沿用模板示例（“项目组”“2026 年 11 月”），也不要编造，在 fill_layout 的 texts 里把这几处置为空字符串。“感谢聆听”这类通用结束语可以保留或按内容改写。

## 内容页：版式可变，样式不变

第 3–12 页是 10 种版式参考（四栏递进、分层架构、双栏演进、四栏能力与流程、痛点-流程-成果、五步流程、问题与方向、概念与关系链、链路与清单、方案与路线）。这些页只示范“怎么排、长什么样”，不规定数量：

- **几行几列几块完全按内容决定。** 栏数、每栏卡片数、步骤数、层数、指标数、图标行数量都可增减，例如模板里三行五列的格子，实际只有四项时改成 2×2；可以只用一页里的一部分，也可以把不同页的部件组合到一页。不为凑版式编造内容，没有对应内容的块直接删除。
- **单元格样式保持一致。** 复制或新增块时沿用下列样式，不另起一套：
  - 红头卡片：红色渐变标题栏（上两角圆角）+ 白到浅粉渐变卡身 + 轻阴影。
  - 要点卡：白底、6px 圆角、轻阴影；左侧粉底图标，右侧红色加粗小标题 + 红色方块列表。
  - 导语条：页顶浅灰渐变条，左侧图标与红色竖线，关键句红色加粗。
  - 飘带标题：居中深红梯形标签，下方渐隐红线。
  - 结论条：底部浅粉渐变条，左端红色斜角 » 标签，红色加粗居中文字。
  - 其他：红色通栏分节条、箭头形层标签、圆形图标场景行、编号圆圈步骤条、大号红色数字指标、时间轴节点、栏间红色 » 箭头。
- **图标都是占位。** 粉底虚线圆圈只表示“这里放一个图标”，每个占位都要按该块内容的含义生成 SVG 图标替换（线性图标，联通红 #E60012 单色，白底场景用红色、红色标题栏里用白色），保持占位的尺寸和底色样式，不能保留虚线圆圈。
- 所有示例文字都是占位，必须替换为实际内容或删除；页面标题按“N、主标题——副标题”书写，页码按最终位置更新。

## 生成约定

填模板是编辑，不是重画。所有页面都标记为按版式填充：复制最接近的版式页，用 get_layout 读取块与字段，再用 fill_layout 只提交内容（每组块的条目、文字和 SVG 图标）。宿主按条目数复制或删除原块，在原区域内重新排列（如 3×5 改成 2×2），块的底色、渐变、边框、圆角、阴影和字体颜色原样保留。

按内容调整块的数量与排布；文字较多时调整卡片尺寸和换行，不缩到难以阅读，不让文字溢出卡片。内容区在页眉分隔线以下（约 y=100 至 680），不压住页眉品牌区。
