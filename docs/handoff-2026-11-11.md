## 3. 待改清单（按优先级）

### P0 安全
1. **shell 仍能读密钥文件**。文件工具已拦，但 `cat ~/.config/grow/credentials.yaml` 可行。改法：命令沙箱里把 `secret_files()` 遮成空文件（宿主有 bubblewrap 相关支持，见 `SANDBOX_UNAVAILABLE` 分类，需查实际接入点）；无沙箱时，命令文本引用这些路径就拒绝。位置：`src/shell_process.rs`。
2. **AI 擅自用凭据请求外部接口**（主 AI 自加 `probeProviderModels`，用 `${DEEPSEEK_API_KEY}` 调 `/models`，碰巧环境变量为空才 401）。改法：提示词规定凭据只经宿主库使用，调研任务不得用凭据调接口。位置：`prompts/single_agent.md`、`module_author.md`。

### P1 不浪费、流程越用越好（用户最看重"靠流程代码沉淀成长"）
3. **需要用户处理时程序被结束，"继续"只能从头重跑**，已完成的子任务结果全丢（本例 DeepSeek 调研重做一遍）。改法：blocker 改为走已有的暂停机制 `src/single_agent/paused_programs.rs`（目前只在用户发消息时暂停，帧状态保留、可 `resume_previous_program` 从原步骤继续），用户处理后从出错那一步重试。位置：`blockers.rs`、`paused_programs.rs`、`program_flow.rs`。
4. **AI 读不到已保存模块源码**，反复猜 `modules/xxx.js`（实际在 `.codex-workspace-mcp/projects/<项目>/chats/<task>/modules/`）。改法：`session` 库加 `read_module(name, version)`，可复用界面用的 `module_source`（`src/frame_view.rs:302`）。位置：`src/single_agent/project_flows.rs`、`src/agent_program/libraries.rs`。
5. **坏步骤固化进模块后一直沿用**（`readModelConfig` 每次读密钥被拦；`probeProviderModels` 每次 401）。改法：模块调用被宿主拒绝（如 `SECRET_FILE`）或全部失败时标记"需修订"，下次调用自动进入修订并告知原因；修订允许删步骤。位置：`program_flow.rs` 模块执行/修订。
6. **修订模块时声明对不上，报错不给原声明**，AI 要试多次。改法：`no saved implementation ... exact declaration` 报错附上已保存的声明原文。

### P2 能力缺口与调教
7. **无 YAML 解析**：AI 手写解析器，4 个提供商 `apiType` 全为 null 且无报错。改法：内置 `yaml.parse`（`builtins.rs`，项目已有 YAML 依赖）。
8. **未配置的库照常显示可用**（web 未配凭据，AI 跑 4 分钟才撞上）。改法：`read_tool_contracts`/`find_library_methods` 标注"未配置及设置位置"。
9. **第二层 AI 越权**（`planDocQueries` 只该出检索词却去搜索；调研子任务去读本地宿主代码）。改法：第二层只给合约声明的工具（`program_task.leaf_tools` 字段已存在，目前为 null）。
10. **猜网址再 fetch**，404 大多来自拼出的 URL，且大量引用第三方聚合站。改法：web 技能 `SKILL.md` 规定先搜后开、结果按来源分级（官方/第三方）并标注。
11. **提示词残留"不要用 Node"类表述**。用户的方针：不告诉 AI 它在写 Node，底层静默映射少量常用 Node API。删掉 `prompts/flow_environment.md`、`module_author.md` 里相关句子。

## 7. 第四轮：探路程序的写法与截断提示（同日，未提交、未打包）

网页版实测（任务 `task_be4688d5…` 第 4 轮）看到两个问题：

- **3 次语法被拒**：都是模块作者的探路程序（`probe:true`）写成了脚本：顶层 `await`、末尾 `return`、顶层 `await probe()`。宿主按模块实现编译，要求顶层只有声明。
  - 1A：探路源码没有定义契约函数、又有可执行的顶层语句时，宿主把顶层代码当作契约函数的函数体运行（`async function 名字(参数) { … }`），参数绑定本次实参，`import` 移到函数之后（照样提升），行号不变。正式实现照旧必须是契约函数。位置 `compiler.rs` `probe_as_entry`、`program_flow.rs` `install_body_with`；提示词 `module_author.md` 与 `write_program` 的说明同步。
  - 1B：报错说清放在哪个函数里：`ReturnNotAllowed` 换成文字说明；顶层 `await` 的报错写明"宿主会用这次的实参调用 X，放进 X 里"，并附上准确签名。
