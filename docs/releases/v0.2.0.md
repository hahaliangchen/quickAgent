# Grow v0.2.0 桌面试用版

本版继续用于实际使用和收集反馈。提供在 Ubuntu 26.04 x86_64 上构建的 Linux 桌面安装包；Windows、macOS 需要分别构建和验证。

## 本版内容

- **配置目录迁到 `~/.config/grow/`**：不再读写 `~/.dsh`。模型提供商写在 `providers.yml`，密钥在 `credentials.yaml`（权限 600），另有 `agent-generation.yml`、`skill-packages.json`。可用 `GROW_CONFIG_DIR` 指定目录，遵循 `XDG_CONFIG_HOME`，Windows 为 `%APPDATA%\grow`。首次启动时如果还没有 `providers.yml`，会从 `~/.dsh`（或 `DSH_HOME`）复制一次旧配置，原文件不改动，之后不再读取。
- **新增“自动审批”权限模式**：凡是“执行前询问”需要确认的操作，先由 AI 对照用户的要求审查。明确该做的直接放行，明确不该做的拒绝，拿不准、审查失败或无法解析时仍弹出审批卡片。每次审批结果会显示在对应的工具调用下面。
- **读取工作区外的路径按权限模式审批**：完全权限直接读取；其他模式弹出审批卡片，可选“仅这次 / 本会话 / 本项目 / 拒绝”。读取授权与命令授权分开记录。写入工作区外的路径仍然一律拒绝，状态库文件在任何模式下都不可读。修复了此前“能列出外部目录、却读不了其中文件”的问题。
- **同名模型按提供商区分**：同一个模型出现在多个提供商下（例如个人与公司两个 DeepSeek key）时，模型菜单只勾选正在使用的那个，思考等级和加速选项按该提供商读取，发送消息时带上提供商；当前模型显示为“模型 · 提供商名”。
- **联网搜索**：内置 `web` 库，使用 DeepSeek 官方 Search/Fetch API。在“设置 → 工具 → 联网搜索”选择一个提供商后可用；搜索凭据独立于对话模型。详见 `docs/web-search.md`。
- 主层提示词调整了执行方式的选择：步骤、工具契约和输入输出都已清楚的熟悉工作才写编排程序。

## 发布检查

- 主程序 release 测试：1009 通过、19 失败、27 忽略。19 项失败的名称与 v0.1.0 记录的失败一致，本版没有新增失败；其中两项仍断言示例使用旧 `@module` 标记。
- VM 测试在 GC 压力模式（`VM_GC_STRESS=1`，每次心跳都回收）下运行：632 通过，失败的只有上述两项 `@module` 断言。
- 新增测试覆盖：配置目录位置与一次性导入、工作区外读取的审批与拒绝、自动审批的放行/拒绝/转交/审查失败、两种模式下需要审查的操作完全一致。
- 前端 TypeScript 检查通过。
- 未将失败测试改为忽略，也没有把本版标为全量测试通过。

## 使用

在 Ubuntu 上安装 `.deb`，或使用随版本提供的 AppImage。从 v0.1.0 升级时，首次启动会自动把 `~/.dsh` 中的模型配置复制到 `~/.config/grow/`；之后在 v0.1.0 中修改的配置不会同步到本版。应用沿用 `com.grow.agent` 标识及系统应用数据目录。

本版只验证当前 Linux 构建环境。安装包保留在本机，不上传 GitHub Release。
