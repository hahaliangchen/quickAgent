# Grow v0.1.0 桌面试用版

本版用于实际使用和收集反馈。提供在 Ubuntu 26.04 x86_64 上构建的 Linux 桌面安装包；Windows、macOS 需要分别构建和验证。

## 本版内容

- Agent 按任务选择最轻的执行方式：直接回答、工具循环或 JavaScript 编排。
- 编排使用 Node.js 风格代码和统一的 JSDoc `@virtual` 声明；已有模块优先复用，必要时进行最小修订。
- 内置 `code_index` 库开放现有 Rust、JS/TS 索引，支持沿符号和引用关系读取源码。
- 合入当前 JavaScript VM 的语法、类成员、CommonJS、内置方法和指令预算改进。
- 源码读取、搜索和文件编辑禁止访问宿主 SQLite 状态文件，避免破坏 WAL 写锁。
- 桌面包包含前端、Agent 后端、内置插件和经过校验的 ripgrep。

## 发布检查

- 前端 TypeScript 检查及生产构建通过。
- Rust 后端 release 构建通过。
- 从 `.deb` 解包后启动桌面端通过：页面和前端脚本正常返回，`code_index` 加载成功，桌面端退出后其后端随之停止；包内后端与本次 release 构建的 SHA-256 一致。
- 主程序 release 测试：996 通过、19 失败、27 忽略。5 项 CommonJS 回归、代码索引库测试及 SQLite 访问保护测试通过。
- 19 项失败中，17 项名称与阶段 8 的既有失败记录一致；另外两项仍断言示例声明使用旧 `@module` 标记，与统一 `@virtual` 后的示例不一致。阶段 8 记录中的另一项旧失败本次通过。
- 未将失败测试改为忽略，也没有把本版标为全量测试通过。完整失败名称见本地打包目录 `desktop/target/release/bundle/validation.json`。

## 使用

在 Ubuntu 上下载 `.deb` 后安装，或使用随版本提供的 AppImage。首次启动后配置模型，选择项目，再开始任务。应用沿用 `com.grow.agent` 标识及系统应用数据目录。

本版只验证当前 Linux 构建环境；AppImage 也可能依赖系统图形库，未验证较旧的 Linux 发行版。安装包校验值见本地打包目录的 `SHA256SUMS`。代码推送到远程仓库，安装包保留在本机，不上传 GitHub Release。
